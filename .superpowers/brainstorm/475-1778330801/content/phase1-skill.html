Phase 1: Skill 系统升级

当前6个 Skill 硬编码在 agent_engine.py 的 TOOLS 数组和 calendar_skill.py 中

1

MCP 协议标准化

将本地函数调用改造为标准的 MCP JSON-RPC 协议，使用官方 mcp 包。Skill 独立为服务进程，通过 stdio/HTTP 通信。

好处

  • 协议标准，可复用
  • Skill 可独立部署

成本

  • 架构改造量大
2

插件式 Skill 注册

不改变调用方式（保持本地函数），但实现 @skill 装饰器 + 自动发现机制。新增 Skill 只需写一个函数 + 装饰器。

好处

  • 轻量，改动小
  • 易于扩展

不足

  • 非标准协议
3

新增 Skill

丰富工具集：auto_summarize（自动总结）、batch_operation（批量操作）、calendar_import/export（导入导出）

4

热加载 Hot-Reload

运行时动态加载/卸载 Skill 插件文件，无需重启服务
