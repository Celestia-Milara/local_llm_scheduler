Phase 1: Skill 系统升级 (修正版)

Skill = 自然语言指令 (.md) + 可选工具实现 (.py)

Skill 是什么

# skill/schedule-management.md

---
name: 日程管理
description: 创建、查询、修改、删除日程
triggers: ["添加日程", "查看安排", "修改会议"]
tools: [add_event, query_events, update_event, delete_event]
---

## 行为规则
- 添加日程前必须先用 check_conflict 检查冲突
- 用户说"明天"、"下周"等相对时间 → 基于当前日期 {current_date} 推算
- 时间格式统一为 ISO 8601

## 约束
- 标题不超过 100 字
- 时间范围必须合理（结束 > 开始）

→ 系统启动时扫描所有 .md 文件，解析 frontmatter + body

→ 动态注入 agent_engine.py 的系统提示词

Skill 与 Tool 的关系

Skill
.md 指令文件
告诉 AI "怎么做事"
→ 引用 →
Tool
.py 函数实现
给 AI "动手的能力"

数据流

启动时:
  loader.py
    ├── 扫描 skills/*.md → 解析 frontmatter + body
    ├── 扫描 tools/*.py → 导入 + @skill 注册
    └── 生成 system_prompt + TOOLS → agent_engine

运行时:
  用户输入 → POST /chat (SSE)
    → agent_engine.run_chat()
      → 系统提示词 = 基础指令 + 所有 Skill .md 内容
      → TOOLS = 所有注册的 Tool 函数
      → Ollama Function Calling → 执行 Tool → SSE 逐字推送

热加载:
  watchfiles 监听 skills/ 和 tools/ 目录
  → .md 变化 → 重新生成 system_prompt
  → .py 变化 → 重新 import → 更新 TOOLS
