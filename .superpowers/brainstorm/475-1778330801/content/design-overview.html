整体架构设计

"设计时就支持两种部署模式，而非事后兼容"

部署模式对比

纯本地模式
用户设备
├── Vue 前端 (静态)
├── FastAPI 后端
├── SQLite 数据库
└── Ollama (localhost:11434)

→ 无需认证，无需网络
云端部署模式
云服务器
├── Vue 前端 (静态)
├── FastAPI 后端
├── PostgreSQL
├── Ollama
└── HTTPS + JWT

→ 用户自部署 Ollama 或服务端内置

配置化开关

一个环境变量控制部署模式：

# .env
DEPLOY_MODE=local          # local | cloud
# cloud 模式下自动启用:
# - JWT 认证中间件
# - HTTPS 强制
# - 数据加密
# - 多用户数据隔离
